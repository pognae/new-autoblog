### 4. 기존 코드 버그 수정 및 최적화를 위한 듀얼 모니터급 파트너십

개발자들에게 **Claude 3.5 Sonnet 활용법**은 마치 내 옆에 상주하는 초엘리트 시니어 개발자 동료 한 명을 두는 것과 같습니다. 터미널에 찍힌 수십 줄짜리 에러 로그와 현재 작성 중인 소스 코드를 같이 붙여 넣고 버그를 찾아달라고 해보세요.

```python
# 기존의 비효율적인 코드 예시 (수정 전)
def find_users(user_ids, database):
    result = []
    for id in user_ids:
        for user in database:
            if user['id'] == id:
                result.append(user)
    return result
```

위와 같이 O(N^2)의 시간 복잡도를 갖는 비효율적인 비즈니스 로직을 던져주며 "이 코드의 실행 성능을 최적화하고 에러 핸들링을 추가해 줘"라고 요청하면, 딕셔너리 구조를 활용한 O(N) 알고리즘으로 즉시 리팩토링해 줍니다. 단순한 코드 생성을 넘어 **왜 이 방식으로 수정해야 하는지에 대한 명확한 기술적 이유까지 설명**해 주기 때문에 실력 향상에도 엄청난 도움이 됩니다.

> 앤트로픽 모델은 XML 태그(`<context>`, `<instructions>`, `<example>`)를 매우 잘 알아듣습니다. 프롬프트 구분을 태그로 감싸서 작성해 보세요.

```xml
<context>
새로운 AI 도구를 도입하려는 중소기업의 마케팅 팀 상황입니다.
</context>

<instructions>
1. 팀원들의 업무 부담을 줄여줄 수 있는 Claude 3.5 Sonnet 활용법 3가지를 제안해 주세요.
2. 각 활용법마다 도입 시 기대효과를 구체적으로 적어주세요.
</instructions>

<format>
각 항목은 실행 가능한 형태의 가이드라인 구조로 작성해 주세요.
</format>
```
