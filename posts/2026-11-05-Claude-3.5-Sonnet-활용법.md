## 🚀 Claude 3.5 Sonnet 활용법 1단계: 마법 같은 '아티팩트(Artifacts)' 완벽 제어하기

Claude 3.5 Sonnet 활용법을 말할 때 절대 빼놓을 수 없는 핵심 기능이 바로 **'아티팩트(Artifacts)'**입니다. 이 기능 하나만 제대로 써도 기존 작업 시간의 절반 이상을 아낄 수 있습니다.

### 아티팩트(Artifacts)가 도대체 무엇인가요?
기존의 AI 대화창은 사용자가 질문을 던지면 길고 긴 텍스트가 줄줄이 내려오는 방식이었습니다. 코드를 짜 달라고 하면 대화창 안에 코드 블록이 길게 생성되어 아래로 스크롤을 한참 내려야 했죠. 

하지만 아티팩트 기능이 켜지면 화면이 **왼쪽(대화창)**과 **오른쪽(작업 결과물 창)**으로 2분할됩니다. AI가 생성한 코드, 대시보드, 프론트엔드 UI design, 마인드맵, 작성된 문서 등이 오른쪽 창에 실시간으로 시각화되어 나타납니다.

```
+------------------------------------+------------------------------------+
|            Left: Chat              |          Right: Artifacts          |
|                                    |                                    |
| User: 대시보드 화면 하나 만들어줘  | [실시간 웹페이지 preview]           |
|                                    |  --------------------------------  |
| Claude: 네, 아래와 같이 작성했습니다. |  | 매출 현황 | 사용자 수 | 그래프 | |
|                                    |  --------------------------------  |
|                                    | [Code 탭 클릭 시 소스코드 확인]   |
+------------------------------------+------------------------------------+
```

### 아티팩트 기능을 200% 끌어올리는 실전 팁
1. **설정 확인하기**: 화면 좌측 하단 본인의 프로필 이름 옆 설정(Settings) 메뉴로 들어가 'Feature Preview' 탭에서 Artifacts가 활성화되어 있는지 가장 먼저 체크하세요.
2. **실시간 수정 요청**: 오른쪽에 뜬 결과물을 보고 "오른쪽 상단 버튼 색상을 파란색으로 바꾸고, 클릭하면 팝업창이 뜨게 해줘"라고 말해보세요. Claude가 코드 전체를 새로 출력하지 않고 오른쪽 창에서 해당 요소만 깔끔하게 수정해 줍니다.
3. **결과물 즉시 내보내기**: 오른쪽 창 하단의 버튼을 통해 작성된 코드를 일일이 복사할 필요 없이 HTML, SVG, React 코드 형태로 즉시 다운로드하거나 외부로 공유할 수 있습니다.

제가 개인 프로젝트로 간단한 포트폴리오 웹사이트를 만들 때 이 아티팩트 기능을 활용해 보았는데요. 디자인 스케치부터 시작해서 실제 작동하는 반응형 웹페이지 코드를 완성하는 데 단 **15분**밖에 걸리지 않았습니다. 기존 방식대로라면 최소 하룻밤은 꼬박 새워야 했을 작업이었습니다. 이 맛을 한번 보면 진짜 과거로 돌아갈 수 없게 됩니다.
